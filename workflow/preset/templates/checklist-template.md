# 教学评审清单：<lesson title>

> 硬项失败即阻断；确需放行必须写书面豁免并老师批准。VLM 只作辅助。

## A. 课件脚本（人类可读内容源）

- [ ] 每屏都有屏幕内容、交互设计、旁白、转场、制作字段
- [ ] 屏幕内容与旁白分离；旁白是逐字稿，不照读屏幕全文
- [ ] 每个互动写清学生动作、成功反馈、错误反馈（绑定误区）、完成条件、重置
- [ ] 核心概念台账（`concepts.yml`）完整；每个概念的术语、定义与 `mustAppear` 短语出现在 `introducedOn` 屏的屏幕内容里，强化/评估页实际使用该概念，`check-concepts` 通过
- [ ] 每个 `watch` 屏有静态替代；每个 objective 至少一个 `answer` 级及以上互动
- [ ] 无 TODO/TBD/待定/占位文本；例题、代码与输出、测验题干/选项逐字出现
- [ ] 脚本 `status: APPROVED`，且与 `storyboard.yml` 投影一致
- [ ] `review-sections.yml` 连续、无重叠覆盖全部非 SKIP 屏
- [ ] 每一节都有老师逐屏渲染审核记录（`section-approvals.md`），且已批准小节未被改动

## B. 组件复用与生成

- [ ] `component-plan.md` 对每个交互需求有检索记录（命令 + 命中结果）
- [ ] 优先复用风格包/注册表组件；不满足时有逐条理由
- [ ] 每个 `new`/`extend` 有简报，且简报已获人工 `approve`
- [ ] 新组件包自包含（实现/stories/tests/基线），`check-staged-components` 通过
- [ ] 状态机每条 transition 有测试；无障碍、静态降级、视觉基线完整
- [ ] 注册后 `status: core`，`check-registry` 通过；页面引用的是注册版本
- [ ] 无一次性私有组件、无未注册组件、无 `deprecated` 组件

## C. 内容覆盖

- [ ] content pack 所有 `required: true` 项都被非 SKIP 屏引用
- [ ] 知识点、例题、测验、讲解、代码与输出、结构/步骤/旁白均已覆盖
- [ ] 没有删减参考内容；新增内容已标记来源与理由
- [ ] 无敏感个人信息/未授权资产

## D. 页面级硬项

- [ ] P2：页内每个元素可标为“证据/必要控件/导航”，标不出则删
- [ ] P3：动画每步的“变化元素清单”与说明文字点名元素一致
- [ ] P4：动画分段，每段末暂停待点击；无整段自动连播
- [ ] P5：术语/符号/颜色首次使用前已定义，登记在共享图例
- [ ] P6：说明文字与所指图元同屏（基准视口）
- [ ] P10：断言与关键图示不点击/不悬停即可见（先答后揭除外）

## E. 互动级硬项

- [ ] I1：每个互动绑定目标 ID
- [ ] I2：标参与度/ICAP 层级；“上一步/下一步/播放”记为观看
- [ ] I3：每个目标至少 1 个“回答”级及以上互动（豁免须写理由）
- [ ] I4：先答后揭；提交前答案/下一帧/标准答案不可见
- [ ] I5：每个错误选项有非空反馈；反馈讲清为何错/对应误区
- [ ] I6：绑定误区库；含 ≥1 个“先暴露 → 再反驳”互动
- [ ] I9：控件取自共享组件库；新控件首次出现前有热身

## F. 技术硬门禁

- [ ] `check-script`：脚本 schema/覆盖/内容存在性
- [ ] `check-review-sections`：小节分组完整且屏均 APPROVED
- [ ] `check-section-freeze --require-all`：全部小节已渲染审核并冻结
- [ ] `script-to-storyboard --check`：脚本与分镜一致
- [ ] `validate-json`：storyboard/content pack schema
- [ ] `check-coverage`：required 项全部覆盖
- [ ] `check-vocabulary`（含 registry）：组件/版面均已注册，无课件级样式覆盖
- [ ] `check-registry`：注册表与组件包一致
- [ ] `check-overflow`：所有页面无滚动条/裁切
- [ ] 截图基线与参考几何一致
